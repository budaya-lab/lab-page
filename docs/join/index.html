PhD researcher and postdoctoral fellow

We are looking for a PhD researcher and a postdoctoral fellow to work on Computational Social Simulations for Cultural Policy.

What we look for

  • Experience fine-tuning and evaluating open-weights LLMs.
  • Experience managing datasets at different levels of completion, annotation and quality.
  • Maintaining and documenting Python code libraries, and comfort working with GitHub and pull requests.
  • Organisational skills: reporting on your code, doing code reviews and similar.
  • Basic Linux sysadmin: SSH-ing into remote compute instances, working with virtual environments and managing batch processing jobs.

No specific background or qualifications are required.

How to apply

  1. Pick the code or data project that best shows your skills in LLM fine-tuning, LLM evaluation, or data management for LLM fine-tuning or evaluation. It doesn't need to be related to cultural policy.
  2. Refactor the code following the guidelines in our Wiki.
  3. Share it with the PI as a private GitHub repository. Use his personal GitHub account, not the lab's; you can find it by following the links on this site.

Please don't send a CV or research proposal at this stage, just the repository. We will continue the conversation from there.
